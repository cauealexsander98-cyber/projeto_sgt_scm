# Sistema de Gerenciamento de Tarefas (SGT)

Projeto desenvolvido para a atividade prática de Gestão de Configuração de Software.

## Objetivo
Organizar e gerenciar tarefas de maneira simples.

## Funcionalidades
- Cadastro de tarefas.
- Consulta de tarefas.
- Organização de tarefas.

Atualização realizada durante a atividade prática de Gestão de Configuração de Software.
